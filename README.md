🧮 Calculadora em React

Uma aplicação de calculadora simples e funcional desenvolvida em React, focada em boas práticas de manipulação de estado (useState) e validação de dados.

🚀 Funcionalidades

Operações Matemáticas:

Soma (+)

Subtração (-)

Multiplicação (*)

Divisão (/)

Validações do Formulário:

Alerta quando algum campo está em branco.

Proteção contra divisão por zero.

Checagem para garantir o envio de números válidos.

Função Limpar: Zera os campos digitados e esconde o resultado da tela.

Interface Limpa: Estilização simples e centralizada via CSS.
